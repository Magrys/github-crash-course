# Kurs Git i GitHub

Witaj w repozytorium Kursu Git i GitHub! Ten projekt zawiera podstawowe materiały do nauki systemu kontroli wersji Git oraz platformy GitHub.

## Struktura projektu

- `index.html` - Główna strona kursu
- `styles.css` - Style CSS dla strony
- `logo.svg` - Logo kursu

## Jak uruchomić

1. Sklonuj repozytorium: `git clone <url-repozytorium>`

2. Otwórz `index.html` w przeglądarce internetowej

## Podstawowe komendy Git

Oto kilka podstawowych komend Git wraz z wyjaśnieniami:

- `git init`: Inicjalizuje nowe repozytorium Git w bieżącym katalogu.
- `git add <plik>`: Dodaje określony plik do obszaru przygotowania (staging area).
- `git commit -m "wiadomość"`: Zapisuje zmiany w repozytorium z podaną wiadomością.
- `git status`: Wyświetla status plików w repozytorium (zmodyfikowane, dodane, itp.).
- `git log`: Pokazuje historię commitów w repozytorium.
- `git branch`: Wyświetla listę gałęzi lub tworzy nową gałąź.
- `git checkout <gałąź>`: Przełącza się na określoną gałąź.
